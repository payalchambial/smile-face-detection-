# Smile Face Detection  A computer vision-based project that detects human faces and identifies whether a person is smiling using Python and OpenCV.  ## Technologies Used - Python - OpenCV - Computer Vision - Haar Cascade Classifier  


## Features
- Real-time face detection
- Smile detection
- Webcam-based detection
- Displays detection results on the screen

## How It Works
The system captures video through a webcam, detects faces using OpenCV, and analyzes the detected facial regions to identify smiles.

## Purpose
The project demonstrates the use of computer vision and image processing techniques for real-time face and smile detection.

## Project Type
Computer Vision Project using Python and OpenCV
